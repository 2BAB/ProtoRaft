# Contributing to Morrow

Use Node.js 22.12 or newer to validate the sample source:

```sh
node scripts/validate-sample.mjs
```

Keep each wireframe, screen definition, route, and linked document in sync.
Morrow uses fictional content. Include attribution for assets you redistribute.

Treat changes to the audio-player example as a Git branch comparison. Run the
validator with `--structure-only` when working from a source archive or when
checking sample files independently of their Git branches.
